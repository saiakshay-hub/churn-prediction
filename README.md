# Customer Churn Prediction | Machine Learning

Built an end-to-end Customer Churn Prediction system using Python and machine learning to identify customers who are likely to discontinue a service.

Performed data cleaning, preprocessing, encoding, and feature engineering.
Handled categorical features and prepared data for model training.
Applied classification algorithms and ensemble learning to predict customer churn.
Evaluated model performance using appropriate classification metrics.
Structured the project as a reproducible ML workflow from preprocessing to prediction.

Tech Stack: Python, Pandas, NumPy, Scikit-learn, Matplotlib/Seaborn, Machine Learning
